## Overview

Notebook brings a simple writing workspace and English typing practice into one place. Keep separate pages for your thoughts, style individual passages, sketch on the page, and export a copy when you need it.

> **Your notebook is personal.** Notes are stored in the browser you use — this is not a public posting platform or a shared cloud workspace.

## Features

| Feature | What you can do |
| --- | --- |
| **Multiple pages** | Create and navigate separate pages for different ideas. |
| **Mixed fonts** | Change the font of selected text, or choose a font for what you type next. |
| **Page styles** | Choose Ruled, Blank, Grid, Dotted, or Wide ruled paper. |
| **Text marking** | Highlight, color, underline, and clear formatting from selected passages. |
| **Live color typing** | Choose a color for newly typed text without recoloring the whole note. |
| **Pencil drawing** | Sketch with adjustable ink color and stroke width. |
| **Typing practice** | Practice English passages with difficulty options, speed, accuracy, and keyboard feedback. |
| **Backup & export** | Download plain text, styled HTML, or a JSON backup for restoration. |
| **Paper themes** | Use System, Warm, White, or Night paper. |
| **Responsive layout** | Use the workspace on desktop or a mobile-sized screen. |

## Getting started

1. **[Open the live website](https://sarafi01.github.io/Notebook/).**
2. Give your page a title and start writing.
3. Add another page when you want a separate space.
4. Open **Marking tools** to format text or use the pencil.
5. Choose **Typing test** to switch to English practice.
6. Use **Settings → Download backup** to keep a copy of your notes.

### How font selection works

- **Nothing selected:** the chosen font applies to your next typing; existing text stays unchanged.
- **Text selected:** only that selection changes font.
- **Whole current note:** click inside the writing area, press **Ctrl+A** (**Cmd+A** on Mac), then choose a font. Other pages are not changed.

Fonts use the families available on your device, with fallbacks. Some choices may look similar if a font is not installed.

## Data & privacy

- Notes and practice history are saved in your browser's local storage.
- This version has no account-based sync, shared database, or public post feed.
- Your notes do not automatically appear in another browser or on another device.
- Clearing browser data, using private browsing, or changing the site's address can affect access to saved notes.
- Keep important work backed up. Local storage is not a substitute for a backup.

### Choose the right export

| Format | Best for |
| --- | --- |
| **JSON backup** | Restoring pages, settings, text formatting, and drawings in the app. |
| **Styled HTML** | Reading or printing a formatted copy. It is not an editable backup. |
| **Plain TXT** | Keeping the written content without fonts, colors, or drawings. |

To restore your notebook, use **Settings → Restore backup** and select your JSON file. Restoration replaces the current notebook, so back up any current work first. Use version 4.4 or newer to restore mixed-font backups.

**Never upload a personal JSON backup to this public repository.**

## Run locally

Download `index.html` and open it in a modern browser. No installation or build step is required.

The local file and the live website may use different browser storage. Move notes between them with JSON backup and restore.
